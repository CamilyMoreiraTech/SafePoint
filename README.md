## 🌙 Sobre o projeto

Muitos servidores de jogos, artesanato e leitura acabam se tornando ambientes tóxicos para mulheres, o que dificulta encontrar pessoas para jogar, conversar, ler e compartilhar interesses com segurança. Hoje não existe um lugar centralizado para consultar a experiência de outras usuárias antes de entrar em um servidor.

O **SafePoint** resolve isso: as usuárias se cadastram, indicam servidores e os avaliam com notas e comentários em critérios como segurança, moderação, acolhimento e respeito. Esses dados alimentam uma dashboard com rankings, gráficos e indicadores, mostrando quais servidores são os mais seguros e como está o cenário geral desses espaços.

## 🎮 Para quem é

Mulheres que se encaixam em um ou mais destes nichos e buscam comunidades acolhedoras:

| Nicho | Abrangência |
|---|---|
| 🎮 Games | Todo tipo de jogo. |
| 🧶 Artesanato | Todo tipo de artesanato. |
| 📚 Leitura | Todo tipo de leitura. |

A proposta é reunir esses três nichos em um único espaço, incentivando o compartilhamento de experiências e a construção de comunidades mais acolhedoras.

## 🛠️ Tecnologias

As tecnologias previstas para o desenvolvimento do SafePoint são:

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura das páginas. |
| CSS3 | Estilização e identidade visual. |
| JavaScript puro | Interações e lógica do front-end, sem frameworks. |
| Chart.js | Criação dos gráficos da dashboard. |
| Node.js | Ambiente utilizado para executar o back-end. |
| web-data-viz | API fornecida pela faculdade. |
| MySQL | Armazenamento dos dados. |
| VS Code | Edição do código e execução do front-end com Live Server. |
| MySQL Workbench | Criação e gerenciamento do banco de dados. |
| Git e GitHub | Versionamento e hospedagem do código-fonte. |
